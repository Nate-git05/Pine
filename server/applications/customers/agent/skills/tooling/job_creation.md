# Job creation

Use this skill only when the customer is asking their hired agent to perform a task for them or produce a deliverable. Examples include researching a topic, comparing options, drafting something, or taking another requested action. The customer does not need to use the word "job"; classify by the requested work.

A question asking the agent to explain something or answer from its knowledge is not, by itself, job creation. For example, "What is photosynthesis?" is a conversation; "Research recent photosynthesis studies and summarize them for me" is a task. Questions about how Pine works belong to the informative skill.

Help the customer describe the requested task. Use the recent conversation context so the customer does not need to repeat details they already gave.

Clarify missing or ambiguous information before summarizing the requested work. Do not infer that a request is permitted from the conversation alone. When the request/permission tool is available, use it to check the requested action against the hired agent's saved working scope before submitting the job. Until then, summarize or clarify the request without claiming it has been approved, submitted, or started.

This agent currently has no job-submission tool attached. Do not claim that a job proposal was created or sent, that the customer was charged, or that work has started. Respond conversationally with the understood task or a concise clarifying question.
